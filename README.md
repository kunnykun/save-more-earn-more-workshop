# Automating Your Business Using Agents — Save More, Earn More
### Welcome! This is your workspace for today.

Today runs as three joint builds, done together, then a self-paced block:

- `project-1-email-followup/` — **JOINT BUILD 1** — draft replies to inbound leads, triage by urgency, then take the same agent live as a Telegram bot on your phone
- `project-2-invoice-processing/` — **JOINT BUILD 2** — receive a supplier invoice, compare it to the purchase order, flag it for payment or for review, and prepare what goes to the accountant
- `project-3-customer-reviews/` — **JOINT BUILD 3** — reply to a batch of online reviews in the right tone, and flag which ones need a phone call instead of a public reply
- `project-4-your-own-task/` — apply what you've learned to your own real task
- `bonus-meeting-notes/` — **bonus pattern**, try it if you finish early or your own task fits it better

Once you've finished a joint build, if you have time left, `materials/bonus-build-a-ui.md` shows an optional way to turn any of these into a one-click app with a button, instead of typed prompts.

Each has its own `README.md` with the exact steps for that exercise — Sohan will tell you which one to open first.

**Before anything else:**
1. Open the file called `.env.example`, then save a copy of it named `.env` (or just rename it) — this is already done for you automatically when your Codespace finishes loading.
2. Open `.env`, paste the key from your seat card between the quotes, save (Ctrl/Cmd+S).
3. In the terminal at the bottom, type `source .env` and press Enter.
4. Type `claude` and press Enter. Say hello to confirm it's working.

**Stay in this one Claude Code session for the whole day** — no need to exit or restart it between exercises. Each project's `README.md` gives you prompts that already include the folder name (e.g. `project-1-email-followup/leads.csv`), so you can just keep typing into the same window.

Then head into `project-1-email-followup/README.md` to begin.

There's also a `materials/` folder with today's agenda and the two worksheets (Find Your $10K Task, 90-Day Roadmap) — everything you fill in stays right here with your builds.
