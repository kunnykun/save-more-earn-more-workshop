# Personal Build — Your Own Task

Same Claude Code session, still no need to restart it.

Drop your own data into this `project-4-your-own-task/` folder — your real inbox export, your overdue-invoice list, a recent meeting transcript, or something else entirely if your $10K task from this morning's worksheet doesn't fit any of the three patterns.

Then reuse the same four-step shape from the joint builds, just pointed at your own file:

1. **Look at the data** — "Read project-4-your-own-task/[your file] and summarize it."
2. **Draft the output** — describe exactly what you want produced, and how it should sound.
3. **Add judgment/triage** — ask it to flag what needs attention first, or to make a call about priority.
4. **Add a guardrail** — one rule it must never break.

That's the whole transferable skill from this morning. Raise your hand if you get stuck.
